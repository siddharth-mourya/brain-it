# Glossary

| Term | Meaning |
| --- | --- |
| DeskBot | Canonical product/documentation name for the desktop companion |
| Expression Bot | Earlier working name focused on facial expressions |
| RobotBuddy | Name used in the prototype firmware comments and web UI |
| Event bus | Internal messaging layer between modules |
| State machine | System that decides the current active bot state |
| Mood engine | Longer-term personality model that modifies behavior |
| Animation resolver | Chooses which animation should play for a state/mood/context |
| Animation player | Plays animation frames with timing and interruption rules |
| Renderer | Display-independent graphics interface |
| SH1106 | Common OLED display controller used for low-cost monochrome displays |
| GC9A01 | Round 240×240 TFT display controller |
| ST77916 | Round high-resolution TFT display option |
| NVS | Non-volatile storage for small persistent values |
| LittleFS | Flash filesystem for config, static assets, and animation packs |
| OTA | Over-the-air firmware update |
| SoftAP | WiFi access point mode used for initial configuration |
