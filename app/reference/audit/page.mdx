# Source Audit

This documentation site was created by consolidating the scattered source files in the repository.

## Source files reviewed

| File | Role in original repository | Consolidation result |
| --- | --- | --- |
| `expression-bot.md` | Main product notes, costing, architecture layers | Rewritten into product, architecture, hardware, and firmware sections |
| `context-flow.md` | Plain-text duplicate of the product and architecture flow | Deduplicated into canonical architecture pages |
| `context-2.md` | HTML/Tailwind/Mermaid visualization of the system flow | Converted into Markdown Mermaid diagrams and boot/runtime explanations |
| `implementation-plan.md` | Recommended phases, project structure, plugin model, display independence | Converted into roadmap and implementation guide |
| `deskbot-code.md` | ESP8266 prototype firmware sketch | Summarized as prototype code notes and migration guidance |
| `index.md` | Supplier/resource notes and rough BOM pricing | Converted into hardware guide and BOM |

## Duplicate content removed

The following content appeared multiple times and now has one canonical location:

| Repeated idea | Canonical page |
| --- | --- |
| Inputs → events → state machine → animation resolver → renderer | [System Architecture](/architecture) |
| Input layer responsibilities | [Module Responsibilities](/firmware/modules) |

| Plugin page interface | [Firmware Guide](/firmware) |

## Conflicts normalized

| Conflict | Resolution |
| --- | --- |
| ESP32-C3 target vs ESP8266 prototype | ESP32-C3 is the V1 target; ESP8266 code is reference only |
| 4-second long press vs 1.5-second prototype constant | Product documentation standardizes on 4 seconds |
| Multiple names: Expression Bot, RobotBuddy, DeskBot | DeskBot is used as the documentation/product name |
| Multiple sensor options | RCWL-0516 low-cost path; VL53L0X/LD2410/LD2450 upgrade paths |
| Unsafe personality example in notes | Replaced with safe persona categories |

## Missing information identified

- Final schematic and pin map.
- Final display selection.
- Confirmed component supplier list and current pricing.
- Battery runtime measurements.
- Asset encoding format.
- OTA implementation details.
- Backend API contract for registration, config sync, and connected bots.
- Enclosure and mechanical constraints.
